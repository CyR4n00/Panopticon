# 3D RPG Project (Panopticon) - 開発マニュアル

Godot 4を用いた、円柱状の塔「パノプティコン」を舞台とする3D RPGのベースプロジェクトです。

## 🐣 超初心者向け：まずはここから！(サンプルの動かし方)

説明書を読んで設定するのが難しい場合、**既に全て設定済みのサンプルシーン**を用意しています。
まずは以下の手順で、ゲーム画面を動かしてみましょう！

### 1. プロジェクトを開く
1. Godot Engine を起動します。
2. 「Import (インポート)」ボタンを押し、このフォルダにある `project.godot` を選んで開きます。

### 2. サンプルレベルを遊んでみる
1. 画面左下の **「ファイルシステム (FileSystem)」** ドックを見てください。
2. フォルダを `res://` -> `scenes` -> `main` と展開します。
3. その中にある **`sample_level.tscn`** をダブルクリックして開きます。（画面中央に3Dのマップが表示されます）
4. 画面右上のほうにある **「シーンを再生 (Play Scene)」** ボタン（🎬 カチンコと再生マークが合わさったアイコン。ショートカットキーは `F6`）をクリックします。

### 3. 操作方法
*   **W / A / S / D キー** または **矢印キー**：プレイヤーを移動します。
*   画面上の赤いボール（敵のシンボル）に触れてみてください。戦闘画面のロードが始まります（ロード画面の仕組みが動くのが確認できます）。

## 🛠 自分でマップを作っていく方法

サンプルシーンで動きが確認できたら、少しずつ自分のゲームを作っていきましょう。

### プレイヤーと敵を自分のマップに置く
先ほどの `sample_level.tscn` のように、自分で作ったマップにもキャラクターを簡単に置くことができます。

1. 新しいマップ（シーン）を作って保存します。
2. ファイルシステムの `res://scenes/main/` の中にある **`player.tscn` (プレイヤー)** を、画面中央の3Dビューにドラッグ＆ドロップします。これだけで操作可能なプレイヤーが配置されます。
3. 同じように **`enemy_symbol.tscn` (敵)** もドラッグ＆ドロップで配置できます。

### パノプティコン（円形刑務所）のマップを生成する
1. メニューの「シーン」->「新しいシーン」を作り、一番上のノード(Node3D)に `scripts/tools/panopticon_generator.gd` をアタッチ(ドラッグ＆ドロップ)します。
2. 画面右側のインスペクター(Inspector)に `Generate Now` というチェックボックスがあるので、それをクリックします。
3. 自動的に円柱状の塔のマップが生成されます！

## 📖 より詳しい仕組み（中級者向け）

最初はこの部分は飛ばしても大丈夫です。慣れてきたら設定を変えてみましょう。

### カメラの切り替え設定
マップの場所によってカメラを切り替えたい場合の設定です。
1. `Area3D` を作成し、`scripts/systems/camera_zone.gd` をアタッチします。
2. プレイヤーがそこに入ったときに切り替える `Camera3D` をInspectorの「Linked Camera」にセットします。

### ステータスデータの作り方
1. ファイルシステムで右クリック -> 「新規作成 (Create New)」 -> 「リソース (Resource)」を選びます。
2. `BaseStats` (ステータス), `EnemyData` (敵データ), `ItemData` (アイテム) のいずれかを選んで作成します。
3. 作成したファイルをダブルクリックすると、右側の画面(Inspector)でHPや攻撃力などを入力できます。
